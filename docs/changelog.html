What's new in The Hot Seat, newest first.

v0.1.4 November 18, 2026

New

  • See who voted. Never Have I Ever and Would You Rather cards now list who voted each way under the prompt, not just the totals on the buttons. Change your vote and your name moves with it. Names never ping anyone, and long lists end with "+N more".
  • Voter names setting. Server admins can turn voter names off with /settings voter-names enabled:False so cards show vote counts only. It's on by default, and /settings view shows the current setting.
  • Website. This site, with the Terms of Service, Privacy Policy, and this changelog.

Updated

  • Privacy Policy: votes on a card are visible to the channel unless the server turns voter names off.

v0.1.3 November 14, 2026

New

  • Prompt search for the review team. /hs-admin search finds prompts by word or phrase, ignoring capitals and accents. Use | to search several terms at once, and filter by game, status, and page.
  • Similar-prompt check. Every submission in the review queue lists up to 3 prompts already in the deck on the same topic, so reviewers can catch repeats that are worded differently.

v0.1.2 November 14, 2026

New

  • 18+ default mode. /settings adult takes a mode: Mixed (clean + 18+) or 18+ only, used by default in 18+ channels. Players can still pick a rating themselves.
  • /settings view shows the default mode and whether the bot could check the server's Age-Restricted setting.

Fixed

  • If the bot can't read a server's Age-Restricted setting, it now says so and explains the fix instead of quietly serving clean prompts only.
  • Next, Truth, Dare, and Random buttons follow the server's current settings on every click, unless the player picked a rating.
  • Empty-deck messages explain when the other rating still has cards.

v0.1.1 November 13, 2026

Fixed

  • 18+ prompts now work in servers set to Age-Restricted server-wide, where Discord has no per-channel toggle.

Changed

  • /settings view shows whether the server is Age-Restricted.
  • Threads in an Age-Restricted server can show 18+ prompts, following the parent channel's settings.

v0.1.0 November 13, 2026

First release.

  • Games: /tod, /truth, /dare, /nhie, and /wyr, with category and rating filters and buttons to keep the game rolling.
  • Live voting on Never Have I Ever and Would You Rather cards.
  • No repeats: each server works through the whole deck before anything comes back around.
  • Community deck: suggest prompts with /submit. Every submission is reviewed before it goes live, duplicates are blocked, and you can choose to have your name shown on the card.
  • Reports: 🚩 any card that doesn't belong. Three reports from different people hide it until a reviewer decides.
  • Server settings: /settings turns 18+ on or off, limits it to chosen channels, and can give a role access to manage the bot.
  • 18+ safety: 18+ prompts only appear in channels marked Age-Restricted in Discord.
  • Privacy: votes are deleted automatically after 14 days.
